# 🛡️ 료그봇 (백수톡 로그봇)

**백수톡** 서버에서 일어나는 일을, 치현 님 개인 서버 `paranoia` 의 비공개 **`#백수톡-로그`** 채널에 남깁니다.
사진·파일은 **원본 그대로 다시 첨부**해서, 원래 방에서 메시지를 지워도 로그 방에는 남습니다.

> 이 폴더는 런처(`백수톡 디코봇`)가 자동으로 켭니다. 여기서 직접 `python bot.py` 로 켜도 됩니다.

## 설정 (`.env`)

```ini
DISCORD_TOKEN=봇_토큰
SOURCE_GUILD_ID=386882960403726337      # 감시할 서버: 백수톡
LOG_CHANNEL_ID=1572394445142360064      # 남길 채널: paranoia #백수톡-로그
LOG_USER_ID=                            # (선택) 디엠 사본
```

- 토큰: https://discord.com/developers/applications/1572393464576876594/bot → **Reset Token**
- 초대: https://discord.com/oauth2/authorize?client_id=1572393464576876594&permissions=126080&integration_type=0&scope=bot
  (백수톡 + paranoia 두 서버에 각각 초대)
  — **메시지 관리** 권한이 포함된 링크입니다. 예전 링크로 초대했다면 이 링크로 다시 한 번 열거나,
  서버 설정 → 역할 → 료그봇 역할에서 `메시지 관리`를 켜면 `/지우개` 가 동작합니다.

## 남기는 것

사진·파일 원본 · 메시지 삭제(본문·첨부까지) · 수정 전/후 · 입장 · 퇴장/추방 · 차단 · 닉네임/역할 변경 ·
음성 채널 입퇴장·마이크/화면공유 상태 · 채널 생성/삭제/변경 · 역할 변경.
봇 자신의 메시지와 `#백수톡-로그` 안의 메시지는 기록하지 않습니다.

## 유틸리티 슬래시 명령어 (v1.0.5~)

디스코드 입력창에 `/` 를 치면 목록이 뜹니다. 상세 안내는 채팅에서 **`/사용법`**.

| 명령어 | 하는 일 |
| --- | --- |
| `/지우개 개수:10` | 이 채널의 최근 메시지 1~100개(기본 10) 삭제. 완료 안내는 실행한 사람에게만 보입니다 |
| `/뽑기 항목:치킨,피자,족발 [팀나누기:True]` | 쉼표로 나눈 항목 중 1개 추첨, `팀나누기:True` 면 절반씩 1팀·2팀 분배 |
| `/투표 질문:... 선택지:치킨,피자,족발` | 2~5개 선택지 버튼 투표. 1인 1표, 다른 버튼을 누르면 표가 옮겨지고, 1시간 뒤 자동 마감 |
| `/타이머 분:25 메모:라면 불 끄기` | 1~180분 뒤 이 채널에 호출자 멘션과 함께 알림 |
| `/공지 제목:... 내용:...` | 라일락 보라색(0xC084FC) 공지 임베드 게시. `\n` 으로 줄바꿈 |
| `/사용법` | 명령어 6종 사용법·주의사항 요약(본인에게만 보이는 임베드) |

- `/지우개` 는 실행자·봇 모두에게 **메시지 관리** 권한이 필요하고, 2주(14일)가 지난 메시지는 디스코드 정책상 일괄 삭제가 안 됩니다.
- `/지우개` 로 지운 메시지는 건별 "메시지 삭제됨" 로그를 남기지 않습니다(같은 채널 20초 동안).
- 슬래시 명령어는 봇이 켜질 때 `tree.sync()` 로 등록됩니다. 구성이 바뀔 때만 다시 등록하며,
  강제로 다시 등록하려면 `tools/log-bot/.command-sync.json` 을 지우고 봇을 다시 켜면 됩니다.
